Here are some of the projects I'm working on and learning from :


### [FIFA Analyst](https://github.com/ayushsail/FIFA-ANALYST)
An AI-powered FIFA World Cup chatbot that answers questions and generates data-backed predictions for the 2026 World Cup. Built with n8n, Pinecone, Cohere, OpenAI, and Tavily, with a custom chat UI.

---

### [DSA in Python](https://github.com/ayushsail/DSA-in-Python)
A collection of Data Structures and Algorithms implemented in Python while learning, practicing, and strengthening problem-solving skills.

---

### [Ai Medical Report Simplifier](https://github.com/ayushsail/Ai-Medical-Report-Simplifier)
AI-powered medical report simplifier that converts complex lab reports (PDF/image) into plain-language summaries with wellness suggestions, supporting 12 Indian languages — built with n8n, OpenAI, and a vanilla JS frontend.
